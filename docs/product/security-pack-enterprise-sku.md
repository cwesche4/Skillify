# Security Pack Access (Enterprise SKU)

## Header

- Title: Security Pack Access
- Description: Security Pack functionality is available on Enterprise plans.

## What the Security Pack Includes

- Audit request workflow
- SOC-2 evidence packet access
- Workspace-scoped exports
- Immutable audit timeline
- Approval-gated delivery

## Access Requirements

- Enterprise plan required
- Workspace membership required
- Admin approval required for exports
- Delivery subject to approval and processing

## What This Page Does Not Do

- Does not initiate requests
- Does not grant access
- Does not provide timelines or SLAs

## Upgrade Guidance (Neutral)

- Security Pack access is enabled through Enterprise agreements.
- Contact your account administrator or account team to request access.

## Legal Footnote

- Security Pack events are generated automatically and may be delayed during approval or delivery.
