# Security Pack Status Notifications (Customer-Facing Copy)

Neutral, enterprise-safe messages for each status.

- **Submitted:** “Your security evidence request has been received and is pending review.”
- **Under review:** “Your request is under review. We will notify you when evidence is available.”
- **Approved:** “Your request has been approved. Evidence will be prepared for download.”
- **Delivered:** “Your requested security evidence is now available to download.”
- **Declined:** “Your request was declined. Please contact support for details.”
