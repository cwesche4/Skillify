# Security Pack Sales Enablement Training (Enterprise)

Deterministic training built from approved artifacts. No pricing, SLAs, roadmap, improvisation, or paraphrasing controls.

## Module 1 — Mental Model (What It Is / Isn’t)

- Script: “Security Pack is governed, contract-entitled evidence delivery with role-gated approvals, server-side enforcement, append-only audits, and 404 concealment for unauthorized/undelivered access.”
- Misconceptions to correct: not self-service, not a certification guarantee, not a SKU upsell, not a speed-over-governance feature.
- Why governance > self-service: reduces legal/procurement risk and keeps evidence auditable.
- Reference: Trust Center copy (show, do not paraphrase).

## Module 2 — Procurement Conversations

- Answer questionnaires using final procurement Q&A; keep responses verbatim and short.
- When to point where: Trust Center for discovery/early review; final questionnaire for procurement/security; compliance packet only on explicit request.
- Guardrail: do not add promises (no SLAs, no custom formats); cite Trust Center sections, not internal docs; do not paraphrase controls.
- References: `docs/sales/security-pack-procurement-questionnaire-final.md`; Trust Center copy.

## Module 3 — Objection Handling Drills

- Use objection handling doc for procurement/security/legal/audit/competitive objections.
- “Say this / Don’t say this” from `docs/sales/security-pack-objection-handling.md`.
- Drills: self-service toggle request; guaranteed approval ask; mutable logs claim; separate SKU ask; custom exports.
- Guardrails: no custom commitments, no guarantees, no SKU toggles; anchor to Trust Center wording.

## Module 4 — Escalation Rules

- Involve Legal for contract/amendment/exception asks.
- Involve Compliance for evidence packet/SOC-2 readiness requests or deep control questions.
- Do not escalate by inventing answers; redirect to approved artifacts.
- References: Positioning decision; Trust Center; readiness artifacts.

## Module 5 — Live Artifact Referencing

- How to cite: show Trust Center sections (access, approvals, audit integrity, non-guarantees) without exposing endpoints; do not paraphrase.
- Evidence references: mention availability of read-only exports/timelines; send questionnaire/packet only when appropriate.
- Guardrail: never send internal docs; use public-safe copy and approved customer-facing artifacts.

## Module 6 — Live Call Scripts

- Discovery: 1-paragraph overview; note no self-service; defer deep questions to Trust Center/Q&A follow-up; show the Trust Center page instead of paraphrasing.
- Security review: walk through entitlements, approvals, audit immutability, data handling using questionnaire + Trust Center copy; share readiness only if requested.
- Procurement handoff: send final questionnaire; remind no SLAs/custom exceptions; compliance packet on request.

## Role-Play Scenarios

- Toggle request → contract entitlement explanation (show Trust Center Access section).
- Guaranteed approval → policy-based approvals + append-only audit requirement (show Trust Center Approvals/Audit).
- Custom evidence format → read-only exports only; no custom formats promised (show Trust Center Transparency/Exports).
- Certification claim → SOC-2 alignment only; no guarantees (show Trust Center Non-Guarantees).

## Certification Checklist (“AE cleared to sell Security Pack”)

- Can deliver the 1-paragraph definition without SLAs or guarantees.
- Can explain entitlements and no self-service in plain English, using Trust Center language.
- Can answer objections using approved responses from objection handling + questionnaire (no improvisation).
- Knows when to use Trust Center vs questionnaire vs compliance packet; does not over-answer or paraphrase controls.
- Follows “do not say” guardrails: no pricing, timelines, certifications, or custom toggles.
