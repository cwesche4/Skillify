# Security Pack — Procurement Blocker Card

## Top Objections (One-line Responses)

1. “Why isn’t this self-service?” → Access is contract-entitlement based and enforced server-side; no UI toggles.
2. “Why can’t we toggle this on?” → Entitlements are granted via contract to keep approvals/audits consistent.
3. “Can we get guaranteed approval?” → Approvals follow reviewer policy; delivery requires APPROVED events plus entitlements.
4. “Is this a SKU/add-on?” → It is included for Enterprise; entitlements, not SKU switches.
5. “What stops data leakage?” → Downloads require delivery + entitlement; unauthorized/undelivered returns 404 and URLs aren’t stored.

## When to Attach the Compliance Packet

- During procurement/security review or when detailed evidence is requested.
- Packet references: compliance overview, evidence index, entitlement enforcement summary.

## Safe Reminders

- No pricing, SLAs, or roadmap.
- Do not offer self-service activation or custom exceptions.
