# AI Governance Control Mapping (Vanta / Drata)

Mapping of existing controls to SOC 2 / Vanta / Drata-friendly fields. No new claims are introduced.

| Framework            | Control ID                 | Control Description                                           | Enforcement Location                                                                                                              | Evidence Source                                                                                                    |
| -------------------- | -------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| SOC2 / Vanta / Drata | CC6 / Access & Kill Switch | Global + workspace kill switch for AI actions                 | `lib/builder/ai/server/assertAiActionsEnabled.ts`, workspace setting routes                                                       | `WorkspaceSettings.aiActionsEnabled`, API `GET/PUT /api/workspaces/{id}/settings/ai-actions`, logs showing 403/503 |
| SOC2 / Vanta / Drata | CC7 / Abuse Prevention     | Workspace+user rate limiting for AI actions                   | `lib/rate-limit/aiActions.ts`                                                                                                     | 429 responses with `retryAfterMs`, `[ai-metric] ai_action_rate_limited`, `[ai-alert] rate_limit_spike`             |
| SOC2 / Vanta / Drata | CC8 / Audit Integrity      | Append-only AI audits with integrity hashes and undo chaining | `prisma/schema.prisma` (AiActionAudit.integrityHash, undoOfId), `lib/builder/ai/server/audit.ts`, `lib/builder/ai/server/undo.ts` | Audit rows showing integrityHash/undoOfId; CSV export `/api/workspaces/{id}/ai-actions/audit/export`               |
| SOC2 / Vanta / Drata | CC7 / Incident Detection   | Alerts for denial, rate-limit, and undo-conflict spikes       | `lib/observability/aiAlerts.ts`                                                                                                   | `[ai-alert]` logs keyed by workspaceId; thresholds in code                                                         |
| SOC2 / Vanta / Drata | CC7 / Monitoring           | Metrics for attempted/applied/denied/undone/rate-limited      | `lib/observability/aiMetrics.ts`                                                                                                  | `[ai-metric]` logs per workspace/action/result                                                                     |
| SOC2 / Vanta / Drata | CC9 / Evidence & Exports   | Audit CSV and evidence bundle endpoints                       | `app/api/workspaces/[workspaceId]/ai-actions/audit/export/route.ts`, `.../ai-actions/evidence/route.ts`                           | CSV with footer metadata; ZIP containing audit.csv and control registry                                            |
| SOC2 / Vanta / Drata | CC7 / Startup Safety       | Fail-fast readiness checks (env, audit table, rate limiter)   | `lib/startup/aiSafetyCheck.ts`                                                                                                    | Startup success; errors on missing env/table; self-audit `lib/governance/selfAudit.ts`                             |
| SOC2 / Vanta / Drata | CC7 / Workspace Isolation  | AI actions require workspaceId and membership                 | AI routes (e.g., `/api/ai/node-improve`, `/api/workspaces/{id}/ai-actions/undo`) enforce membership and workspace scoping         | 403 denials for non-members; audit rows scoped to workspaceId                                                      |
